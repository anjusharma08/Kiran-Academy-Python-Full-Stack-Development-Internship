# SQL Industrial Practical Task – Banking Account Management

## 📌 Project Overview

This practical task focuses on **Banking Account Management using MySQL**.

It covers database creation, table creation, inserting records, retrieving data, updating records, deleting records, and modifying the table structure.

## 🛠️ Technologies Used

* MySQL
* SQL

## 📚 SQL Concepts Covered

* Database and Table Creation
* DDL (Data Definition Language)
* DML (Data Manipulation Language)
* DQL (Data Query Language)
* SELECT statements
* WHERE clause
* AND / OR operators
* BETWEEN / NOT BETWEEN
* IN operator
* LIKE operator
* ORDER BY
* LIMIT
* UPDATE
* DELETE
* ALTER TABLE
* RENAME COLUMN
* RENAME TABLE
* TRUNCATE TABLE
* DROP TABLE

## 🗃️ Database Details

**Database Name:** `banking_db`

**Table Name:** `accounts`

The `accounts` table contains the following information:

* Account ID
* Account Number
* Customer Name
* Account Type
* Branch
* City
* Balance
* Credit Score
* Status
* Opened Date
