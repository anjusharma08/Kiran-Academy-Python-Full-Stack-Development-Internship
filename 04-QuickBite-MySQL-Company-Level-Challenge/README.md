# QuickBite MySQL Company-Level Challenge

## About the Task

This task is part of the Kiran Academy Python Full Stack Development Internship.

In this task, I worked on a fictional food delivery company called **QuickBite Technologies Pvt. Ltd.** The main objective was to practice MySQL queries using restaurant data such as cuisine, city, rating, average order value, orders, delivery fee, delivery time, owner and brand.

## Database Details

* **Database Name:** `quickbite`
* **Table Name:** `restaurants`
* **Number of Records:** 30
* **Database:** MySQL

## Table Columns

| Column              | Description                          |
| ------------------- | ------------------------------------ |
| `restaurant_id`     | Unique ID of the restaurant          |
| `restaurant_name`   | Name of the restaurant               |
| `cuisine`           | Type of cuisine                      |
| `city`              | City where the restaurant is located |
| `rating`            | Restaurant rating                    |
| `avg_order_value`   | Average order value                  |
| `orders_count`      | Number of orders                     |
| `delivery_fee`      | Delivery fee                         |
| `est_delivery_time` | Estimated delivery time              |
| `owner_name`        | Restaurant owner                     |
| `brand`             | Restaurant brand                     |
