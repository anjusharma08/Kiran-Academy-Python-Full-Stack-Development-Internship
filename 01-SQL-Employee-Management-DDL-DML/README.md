# SQL Employee Management System

This practical task is based on the **Employee Management System** using MySQL and SQL. It focuses on SQL DDL commands and basic DML operations for creating and managing employee records.

## 📚 Topics Covered

* 🗃️ Creating a database
* 🏗️ Creating tables
* 📝 Defining columns and data types
* 🔑 Using Primary Keys
* ➕ Inserting employee records
* 👀 Displaying table records
* 🔄 Updating records
* 🗑️ Deleting records
* ✏️ Modifying table structure
* 🔄 Renaming columns and tables
* 🧹 Truncating and dropping tables
